## 鼠标参数问题结论

登录前 move_cursor 失败的原因是同时提供了 `scope` 与 `target`。改用仅含 `target:{kind:"desktop",display_id:"primary"}` 的格式后，移动和点击均实测生效，无需升级 Cua 或修改容器。上一轮手工 RFB 指针回读失败仍未单独诊断，不据此扩大本次结论。

DriverService 的 effect 仍可能为 unverifiable；消息发送通过画面与 AT-SPI 复核，不将 HTTP/RPC 返回或 journal done 当作业务成功证明。
